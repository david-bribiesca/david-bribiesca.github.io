What is HTML?

Es una forma de crear una pagina web a través de elementos definidos como párrafos, encabezados, enlaces, imágenes, etc.

Explain the head and the body tags.

En Head we have the informaciónn adicional que necesita el navegador in order to have better results while searching, mientras que el body is the section where you define the cosas visibles para el usuario.

Basic Tags

Explain the section, article, aside, header, footer tag?

Son etiquitas que permitan una correcta semántica, es decir una mejor estructura. Es como devir que abajo de una persona van los pies, a los lados los brazos, etc. (En teroía se puede hacer una página solo con "pies" pero es una práctica incorrecta). Section sirve para agrupar contenido relacionado.Article sirve para agrupar contienido independiente entre sí, aside sirve para poner información de un lado de la página, header es el menú que va arriba de la mayoría de las páginas, mientras que footer es el de abajo.

What is the purpose of CSS?

El CSS es la herramienta que permite dar estilo y diseño a las páginas web. puede tanto cambiar aspecto, posición, etc.

How do you apply a CSS to an HTML (explain the 3 options) What is a selector?

La primera forma es agregar el atributo style a cada uno de las etiquetas del html, la segunda forma es dentro de unas etiqutas style poder describir el que estilo tendría cada etiqueta, para saber qué elementos se utiliza un selector, que puede ir desde seleccionar todos los elementos, algunos de unas clases, o específicamente uno. Y la tercera y última opción es utilizar un archivo .css separado donde vayan cada uno de los estilos, y es muy similar a la segunda opción, solo que ahora está separado el html del css.

What is a CSS rule?

Una regla indica cómo es que se debe de ver cada elemento en la página. va complementado del selector.
