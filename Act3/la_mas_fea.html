2. CSS

Introduction

What is CSS?

Es un lenguaje de hojas de estilo que usamos para describir la presentación de un documento escrito en HTML. Básicamente, si el HTML es el esqueleto de la página, el CSS es la ropa, el diseño y los colores.

What is the purpose of CSS?

El CSS es la herramienta que permite dar estilo y diseño a las páginas web. puede tanto cambiar aspecto, posición, etc.

How do you apply a CSS to an HTML (explain the 3 options) What is a selector?

La primera forma es agregar el atributo style a cada uno de las etiquetas del html, la segunda forma es dentro de unas etiqutas style poder describir el que estilo tendría cada etiqueta, para saber qué elementos se utiliza un selector, que puede ir desde seleccionar todos los elementos, algunos de unas clases, o específicamente uno. Y la tercera y última opción es utilizar un archivo .css separado donde vayan cada uno de los estilos, y es muy similar a la segunda opción, solo que ahora está separado el html del css.

What is a CSS rule?

Una regla indica cómo es que se debe de ver cada elemento en la página. va complementado del selector.

Basic CSS

Explain a:

  • Tag Selector: Selecciona todos los elementos de un tipo de etiqueta HTML en específico.
  • Class Selector: Selecciona elementos que comparten un atributo de clase específico.
  • Tag and Class Selector: Es la combinación de los dos anteriores.
  • Id Selector: Selecciona un elemento único basándose en su atributo id.

What is a class? What is an id? How are they related to CSS?

Una clase te permite agrupar varios elementos que comparten características, mientras que el id es un identificador único para cada elemento.

Explain the CSS Box Model? Show an example.

En CSS, literalmente todos los elementos son cajas. El Box Model explica la estructura de estas cajas.


    .mi-caja {
        width: 300px;
        padding: 15px;
        border: 2px solid;
        margin: 20px;
    }

Explain the media queries

Son reglas que te permiten aplicar estilos CSS diferentes dependiendo de las características de la pantalla o dispositivo.

Layout CSS

Explain display: grid

Es un sistema de layout bidimensional de CSS. Permite dividir el espacio en filas y columnas.

Explain display: flex

Es un sistema de layout unidimensional. Su propósito es alinear y distribuir el espacio.
